# Public release checklist

- Link the finished edited performance reel in the portfolio README.
- Use an excerpt approved for public performance; retain the full script in the private master.
- Do not publish private creator notes, full bibles, source design files, raw art prompts, editable originals, or the unedited screen recording.
- Do not add a public reuse license.
- Remove any bot image with pupils, limbs, side pods, or other off-model details before publishing.
- Keep only artwork that matches the approved flat 2D show style.
- Before each update, compare the staged files with the private master and confirm that only intended portfolio samples are present.
